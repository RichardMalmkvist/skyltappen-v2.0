# Artikelregister v2

Artikelregistret är nu avsiktligt tomt från start. Artikelgrupperna ligger kvar.

## Bilder
Varje artikel kan ha flera bilder.
- **Kortbild** visas i produktkortet innan kunden öppnar artikeln.
- **Huvudbild** används som artikelns primära produktbild inne på produktsidan.
- Övriga bilder ligger kvar som extra produktbilder.

## Pendlade skyltar
Vid Ny/Redigera artikel kan Produktmall väljas:
- Pendlad skylt 1500 mm
- Pendlad skylt 1000 mm

Välj också Enkelsidig eller Dubbelsidig. Mallens produktionsmått sparas i artikelregistret och används i live-previewn.
