# Roadmap

1. Ny startsida efter login, utan att röra befintligt orderflöde.
2. Admin för artikelgrupper: öppna/stäng befintliga grupper.
3. Admin för artiklar: skapa/redigera/duplicera/inaktivera/radera.
4. Produktionsordrar + godkännandeflöde.
5. Projekt.
6. PDF-ritningar och artikelmarkeringar.
7. Planering med riktig data och drag & drop.
8. Roller och granulära behörigheter.
9. Responsiv förfining för desktop/iPad/mobil.
